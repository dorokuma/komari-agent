# 决策与踩坑笔记

本目录记录项目中关键架构决策、规范约定、踩坑排障与临时 workaround。

## 记录触发条件（满足任一即写）

1. **SQLite schema/索引格式/配置格式/对外 API 契约**：涉及数据存储结构、持久化格式或对外协议变更。
2. **跨两个以上模块或跨仓库**：涉及多子系统交互或跨项目依赖协作。
3. **否决看似更优方案**：排除直觉更佳但存在隐患的备选方案。
4. **临时降级/workaround/特判**：针对特定环境（如 LXC/特定系统调用）的特殊处理。
5. **与 upstream 的故意分歧**：与上游主干行为不一致的本地定制实现。
6. **性能取值原因**：核心性能参数、超时时间或缓冲区大小的选型考量。

## 豁免清单

以下情况可豁免记录（**触发优先于豁免：单文件 workaround 必须记**）：
- 版本 bump
- 纯文案调整
- 行为不变的单文件 bug 修复
- 小版本依赖升级
- 纯补测试用例

## 规范与流程

- **命名规范**：`YYYYMMDD-slug.md`（如 `20260917-lxc-cgroup-cpu.md`）。
- **模板结构**：参考 [_template.md](_template.md)。
- **不可变性**：旧笔记废弃时不直接修改正文，仅更新 frontmatter 中的 `status: superseded` 及 `superseded_by` 字段。
- **索引维护**：编写或更新笔记后，运行 `scripts/notes-index.sh` 自动刷新本地索引。
